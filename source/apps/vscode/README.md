# Session Lens for VS Code

Claude Code usage by day → session → request → context line items, in a VS Code tab.

- **Session Lens: Open** opens the dashboard. Drag its tab to the bottom panel or the far right to pin it apart from your editors.
- The status bar shows today's estimated cost; click it to open the dashboard.
- Settings: `sessionLens.projectsDirs` (transcript folders), `sessionLens.statusBar`.

Reads `~/.claude/projects` locally. Nothing leaves your machine.
